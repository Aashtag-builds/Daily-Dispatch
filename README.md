# Daily Dispatch

A Python-based terminal productivity application that helps users organize tasks, priorities, due dates, and progress.

## Video Demo

[Watch the Video Demo](https://youtu.be/RJRo_vbeVQE)

## Description

Daily Dispatch is a personal Python terminal application designed to make everyday task management simple and organized. It stores tasks locally in a JSON file and provides a daily dispatch, an upcoming-task section, and a progress summary.

The application also includes a small butler cat that reacts to the user's workload and progress, giving the otherwise practical command-line interface a bit of personality.
